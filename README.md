# 互联网数据传输 · 3D 教学动画

一个基于 **Three.js** 的交互式 3D 教学动画，用可视化方式演示"一次完整的数据请求"如何在前端、后端、API 之间流转，并讲解 **JSON 数据格式**。

## ✨ 演示内容

动画以一个典型场景为例：**用户在前端点击「获取用户信息」**，请求穿过互联网到达服务器，后端处理后返回 **JSON 数据**。整个过程拆解为 7 个步骤自动循环播放：

| 步骤 | 名称 | 说明 |
|------|------|------|
| ① | 用户操作 | 用户点击按钮，浏览器生成 HTTP 请求 |
| ② | 请求发出 | 请求包（`GET /api/users/42`）从前端驶向 API 网关 |
| ③ | API 网关 | API 解析路由，把请求转发给后端 |
| ④ | 后端处理 | 后端查询数据库，形成数据对象 |
| ⑤ | JSON 序列化 | 后端把对象序列化成 JSON 字符串 |
| ⑥ | 响应返回 | JSON 响应包经 API 返回前端 |
| ⑦ | 前端渲染 | 前端解析 JSON，渲染页面，传输完成 |

## 🗺 3D 场景拓扑

```
 前端（浏览器） ────── 数据高速公路 ────── 后端（服务器）
        │                                      │
        └──────────── API 网关（中枢） ─────────┘
```

- **蓝色数据包** = 请求（Request）
- **绿色数据包** = 响应 + JSON 数据
- 管道路径上的流动粒子 = 正在传输的数据流

右侧面板实时展示 **JSON 响应数据**，并用不同颜色标注各数据类型的语法：

- 🔵 键名 `"key"`　🟢 字符串 `"value"`　🟡 数字 `42`　🩷 布尔 `true`　🔴 `null`　以及 `{}` 对象、`[]` 数组

## 🚀 如何运行

> 动画依赖 ES Module（`import`），浏览器会阻止通过 `file://` 直接加载本地模块。请用下面的任一方式通过 HTTP 访问。

**方式一：一键启动（Windows）**

双击 `start.bat`，会自动启动本地服务器并打开浏览器。

**方式二：命令行**

```bash
# 在本目录下执行
python -m http.server 8000
# 然后浏览器打开
http://localhost:8000/index.html
```

**方式三：VS Code**

安装 [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) 插件，右键 `index.html` → *Open with Live Server*。

## 🎓 教学要点（JSON 数据格式）

演示使用的 JSON 响应：

```json
{
  "id": 42,
  "name": "小明",
  "role": "全栈开发者",
  "skills": ["JavaScript", "Three.js", "API"],
  "active": true
}
```

JSON 是一种**轻量、易读、跨语言**的文本数据格式，核心规则：

1. 数据以 **键值对** 形式存储，键必须用双引号包裹：`"name": "小明"`
2. 支持 **字符串、数字、布尔值、null、数组、对象** 六种类型
3. **数组** 用 `[]` 表示有序列表，**对象** 用 `{}` 表示无序键值集合
4. 前后端约定用 `Content-Type: application/json` 标识数据格式
